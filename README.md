# 공업 일반 마스터 (배포본)

고등학교 교과 「공업 일반」(2022 개정) 학습도구 · **암호 잠금**

| 파일 | 내용 |
|---|---|
| `index.html` | **유일한 입구** — 배우기 · 테스트 · 종합시험 · 랭크 · 결과제출 + 전자칠판 수업 슬라이드(20차시 · 118장) |
| `board.js` | 전자칠판 수업 슬라이드 화면 — 모든 도구가 함께 쓰는 공용 파일 |
| `lock.js` | 잠금 화면 (공개 · 비밀 없음) |
| `bundle.enc` | 학습 데이터 — AES-GCM 암호화 |
| `enc/` | 교과서 도판 146장 — 한 장씩 AES-GCM 암호화 |

## 왜 암호가 걸려 있나

내용과 도판은 고등학교 「공업 일반」(2022 개정, 부산광역시교육감 인정,
송낙현·최혜진·강은생·윤석현·이재원) 교과서에서 가져왔습니다.
저작권법 제25조는 수업 목적 이용을 허용하되 **접근 제한 조치**를 요구하므로,
화면만 가리는 방식이 아니라 **파일 자체를 실제로 암호화**했습니다.

- 주소를 직접 열어도 알아볼 수 없는 문자열만 나옵니다
- 브라우저에서 암호로 키를 만들어(PBKDF2-SHA256 200,000회) 복호화합니다
- 검색엔진 차단(`robots.txt`)

**한 번 연 기기는 다음부터 그냥 열립니다.** 같은 주소의 다른 도구도 함께 풀립니다.

> 이 저장소에는 평문이 없습니다. 원본과 빌드 스크립트는 로컬 `공업일반-master` 폴더에 있습니다.
> 내용을 고친 뒤에는 그쪽에서 `python build_lock.py --pw <암호> --deploy` 를 돌려 이 폴더를 갱신합니다.
